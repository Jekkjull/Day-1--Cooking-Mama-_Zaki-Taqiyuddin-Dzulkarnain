# Day-1--Cooking-Mama-_Zaki-Taqiyuddin-Dzulkarnain

Penggunaan AI dalam Proses Kerja: Mempelajari cara menyusun prompt AI yang spesifik dan terarah agar menghasilkan keluaran (output) yang jauh lebih optimal, relevan, dan akurat sesuai kebutuhan pengembangan produk.

Manajemen Perubahan dengan Git & GitHub: Memahami perbedaan fundamental antara Git (sebagai version control system lokal) dan GitHub (sebagai platform kolaborasi berbasis cloud). Peserta diajak mengenali komponen dasar seperti repository, commit, branch, dan pull request untuk mengelola perubahan kode atau dokumen secara kolaboratif dan terstruktur.

Day 1 workshop ini memberikan wawasan yang sangat aplikatif dan relevan dengan kebutuhan industri saat ini. Kombinasi antara pemanfaatan AI untuk mempercepat proses pembuatan ide/kefleksibelan kerja dan penguasaan Git/GitHub untuk menjaga kerapian serta keamanan kode menjadi fondasi yang sangat kuat. Materi disajikan secara terstruktur, menjembatani teori desain dan manajemen produk dengan praktik teknis yang nyata di lapangan.
